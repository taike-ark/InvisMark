## 1. 设计目标

### 1.1 我们要的是"光学行为"，不是像素级复刻

液态玻璃（Liquid Glass）是 Apple 在 iOS 26 引入的材质语言，特征有四项：**背景实时折射、边缘镜面高光、透镜式形变、色彩拾取**。我们的实现原则：

| 要素 | 我们怎么做 | 不做什么 |
|---|---|---|
| 背景折射 | 高斯模糊 + 饱和提升 + 边缘 uv 位移（shader，仅焦点玻璃） | 不做全屏实时折射 |
| 镜面高光 | 顶部 1px 内描边 + 左上径向高光 + 按压时高光扫过 | 不逐帧重算光照 |
| 形变 | 按压缩放 0.97、拖拽边缘轻微剪切、进出场模糊渐显 | 不做流体模拟 |
| 色彩拾取 | 玻璃底色由背景平均色决定亮/暗两套 token | 不做逐像素色采 |

> 明确不做：不使用 SF Pro 字体（授权仅限 Apple 平台）、不使用 SF Symbols（同上）。字体用 **MiSans（默认）/ Inter（西文）/ 系统字体兜底**，图标全部自绘或使用开源线性图标集。

### 1.2 四条硬原则

1. **内容优先**：玻璃只做"浮层"（导航、面板、抽屉、按钮），**永远不做页面底色**。
2. **一屏不超过 3 块玻璃**：超过就拆页面或合并面板（性能与视觉呼吸同时受益）。
3. **图片本体上永不叠玻璃**：预览与成图区域保持 100% 干净的像素，玻璃只出现在其边界之外。
4. **永远有降级路径**：任何玻璃都有 Opaque 备胎，低端机与"降低透明度"开关下必须好看。

### 1.3 品牌落点

| 语义 | 颜色 | 用法 |
|---|---|---|
| 主操作（嵌入/保存） | 青绿渐变 `#34D399 → #22D3EE` | 主按钮、进度环、成功状态 |
| 溯源（证据/命中） | 蓝紫 `#818CF8` | 提取命中卡、证据包 |
| 警示（分享风险） | 琥珀 `#FBBF24` | 分享前提示、检出率风险说明 |
| 危险（删除/失败） | 玫红 `#FB7185` | 删除、任务失败 |

## 2. 材质模型（Z 轴五层）

每一块玻璃 = 5 层叠加，顺序固定，缺一层就会"廉价感"：

| 层 | 名称 | 参数（亮色 / 暗色） | 作用 |
|---|---|---|---|
| Z0 | 背景内容 | 图片/渐变，可静态模糊 | 折射来源 |
| Z1 | 玻璃本体 | `blur 24px, saturate(180%)`；白 overlay α 0.14 / 黑 α 0.38 | 材质基体 |
| Z2 | 边缘透镜 | 内描边：顶部 `1px rgba(255,255,255,.55)`，其余 `1px rgba(255,255,255,.14)` | 玻璃厚度感 |
| Z3 | 内容 | 主文字 `rgba(255,255,255,.92)`，次级 `.60` | 文字/图标 |
| Z4 | 投影 | `0 12px 32px rgba(0,0,0,.28)` + `inset 0 1px 0 rgba(255,255,255,.5)` | 悬浮关系 |

**高光公式（可选层，成本极低、观感提升最大）**：

```
background:
  radial-gradient(120% 80% at 15% 0%,  rgba(255,255,255,.22), transparent 60%),   /* 左上镜面 */
  radial-gradient(100% 60% at 85% 100%, rgba(255,255,255,.08), transparent 70%),  /* 右下环境光 */
  linear-gradient(135deg, rgba(255,255,255,.14), rgba(255,255,255,.04));          /* 基体 */
```

**焦点玻璃（Focus Glass）**：每屏只允许 1 块玻璃启用 shader 折射（边缘 2px 内做 uv 正弦位移 + 色散），其余全部用静态模糊。这是"液态感"的主要来源，也是最贵的部分。

## 3. 设计 Token

### 3.1 圆角

| Token | 值 | 用例 |
|---|---|---|
| `radius-xs` | 10 | 小标签、输入框内块 |
| `radius-sm` | 14 | 图标底、小按钮 |
| `radius-md` | 20 | 列表行、提示条 |
| `radius-lg` | 28 | 卡片、玻璃面板 |
| `radius-xl` | 40 | 底部抽屉、大面板 |
| `radius-full` | 999 | 胶囊按钮、TabBar |

### 3.2 间距（4pt 基数）

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40`；页面左右安全边距 20；玻璃面板内边距 20；玻璃之间最小间距 12（重叠会让边缘高光互相污染）。

### 3.3 字阶

| 样式 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| Display | 34 / 40 | 700 | 首页问候、结果页标题 |
| Title1 | 28 / 34 | 700 | 页面标题 |
| Title2 | 22 / 28 | 600 | 卡片主标题 |
| Headline | 17 / 22 | 600 | 按钮、列表主文案 |
| Body | 17 / 24 | 400 | 正文（玻璃上最小可用字号） |
| Footnote | 13 / 18 | 400 | 辅助说明、溯源时间 |
| Caption | 11 / 14 | 500 | 角标、TabBar 标签 |

> 玻璃上禁止出现 < 13pt 且 α < 0.6 的文字：模糊背景会吞掉对比度。

### 3.4 动效

| 场景 | 曲线 | 时长 |
|---|---|---|
| 按压回弹 | `spring(0.34, 1.2)` | 240 ms |
| 抽屉进出 | `easeOutQuint` | 320 ms |
| 玻璃入场（blur 0→24 + α 0→1） | `easeOut` | 160 ms |
| Tab 指示器变形 | `spring(0.3, 1.0)` | 260 ms |
| 高光跟随（倾斜/指针） | `easeOut` | 120 ms |

### 3.5 亮暗双模式差异

| 属性 | 亮色模式 | 暗色模式 |
|---|---|---|
| 玻璃白 overlay | 0.14 | 0.06 |
| 玻璃黑 overlay | 0.06 | 0.38 |
| 内描边亮度 | 0.55 | 0.30 |
| 投影强度 | 0.12 | 0.40 |
| 主文字 | 系统 label（#111） | #F5F7FA |

## 4. 界面结构

### 4.1 首页 Home

```
┌───────────────────────────────┐
│  ← 背景：最近一张图，静态模糊 30px          │
│  ┌─────────────────┐                      │
│  │ 隐迹 · 张*  ⚙   │  ← 玻璃胶囊（标题区）  │
│  └─────────────────┘                      │
│                                           │
│  ┌───────────────────────────┐            │
│  │  ＋   选择图片嵌入水印     │ ← 主玻璃大卡 │
│  │      支持 200 张批量      │   (焦点玻璃, │
│  └───────────────────────────┘    启用折射) │
│                                           │
│  ┌───────────────────────────┐            │
│  │ 🔍 输入追溯码 / 拍照检测   │ ← 玻璃次级卡 │
│  └───────────────────────────┘            │
│                                           │
│  ┌───────────────────────────┐            │
│  │ 本月已嵌入 128 / 1000     │ ← 玻璃数据卡 │
│  │ ▓▓▓░░░░░░░  12.8%         │            │
│  └───────────────────────────┘            │
│                                           │
│  ┌─────────────────────────────┐          │
│  │  ⌂ 首页    ◎ 检测    ○ 我的  │ ← 玻璃 TabBar│
│  └─────────────────────────────┘          │
└───────────────────────────────┘
```

要点：背景图每 24 小时或每次进入时截一张 1/4 尺寸快照做 blur（不实时模糊整图）；主玻璃卡是**唯一焦点玻璃**；TabBar 悬浮，底部安全区留 18pt。

### 4.2 嵌入流程 Embed

- 顶部：返回玻璃胶囊 + 右上"批量（12）"玻璃计数胶囊；
- 中部：**图片预览，绝对不叠玻璃**，圆角 20 由容器裁切；
- 底部玻璃参数面板（`radius-xl` 上圆角）：
  - 输出格式分段控件（PNG 无损 / JPEG 95）；
  - 强度档（标准 / 强鲁棒），下方一行 Footnote 说明代价："强鲁棒 = 画质略降，抗二次压缩更强"；
  - 开关：生成可分享溯源链接；
- 主按钮：青绿渐变胶囊，`56pt` 高，渐变随按压亮度 +8%；
- 次要动作："先预览水印效果"（滑动分割对比，玻璃上不做动画模糊）。

### 4.3 处理中 Processing

玻璃进度卡（`radius-lg`，居中，宽 320）：环形进度（青绿）、阶段文案「预处理 → 编码 → 嵌入 → 回注」、预估剩余秒数、**后台运行**按钮（允许退出当前页继续处理，推送通知完成）。

> 阶段文案必须真实映射处理步骤——这是专业感的来源，也是用户唯一能理解"为什么慢"的地方。

### 4.4 结果 Result

- 成图全屏，双指缩放（缩放时不重建玻璃，仅缩放图片层）；
- 底部玻璃抽屉（可上滑展开到 70% 高）：
  - 一行质量指标：`PSNR 42.7 dB · 检出率 高`（数据来自服务端返回）；
  - 三段动作：保存到相册 / 分享 / 复制溯源链接；
  - 「查看证据包」玻璃行（蓝色图标），进入 Web 报告；
- **分享风险提示**：点"分享"先弹玻璃 sheet（`radius-xl`），列出渠道风险（微信好友=原图较安全；朋友圈/抖音=重压缩，检出率下降），不写"保证可检出"。

### 4.5 检测 Extract

- 相机取景全屏，四角玻璃准星 + 顶部玻璃胶囊（手电/相册/关闭）；
- 取景框中央一行 Footnote：「不支持屏幕翻拍以外的模糊图」；
- 命中：底部玻璃卡上推（`spring`），顶部一条青绿边缘光扫过 → 展示 `trace_id`、归属用户、嵌入时间、置信度环（≥ 0.9 显示"高置信"）、原始图缩略图 + 「生成证据包」主按钮；
- 未命中：同位置玻璃卡显示「未检出」，附可折叠的"为什么"（三档原因：无码 / 损毁 / 尺寸过小），并给"人工复核"入口。

### 4.6 我的 / 记录

玻璃列表行 + 静态缩略图（缩略图**不参与模糊**）；列表滚动时禁用实时模糊（见 §7）。空态用居中玻璃卡 + 一句引导。

## 7. 性能与降级（移动端成败关键）

### 7.1 硬预算

| 项 | 预算 |
|---|---|
| 同屏玻璃数量 | ≤ 3（含 TabBar） |
| 单块玻璃 blur 半径 | ≤ 24 px |
| 玻璃总面积 | ≤ 屏幕 40% |
| 列表/滚动区域 | **禁止实时模糊**，用静态快照 |
| 焦点玻璃（shader 折射） | 每屏 ≤ 1，尺寸 ≤ 屏 50% |
| 帧率目标 | 中端机（骁龙 7 系 / A14）滑动 60 fps，jank < 1% |
| 冷启动 | 首帧不出现玻璃动画（直接 Opaque 首屏，200 ms 后切换） |

### 7.2 三档降级

| 档位 | 条件 | 表现 |
|---|---|---|
| **Full** | 旗舰/近两年中端，持续 ≥ 58 fps | blur 24 + saturate 180 + 焦点折射 shader + 高光扫过 |
| **Lite** | 检测到 200 ms 内平均 < 50 fps，或设备分级 C | blur 12、去掉 shader，用柔和阴影 + 半透明白替代 |
| **Opaque** | 低端机 / 系统"降低透明度"开启 / 省电模式 | 不透明渐变卡片（仍保留圆角与层级，视觉不塌） |

降级是**自动**的（帧率采样 + 设备分级白/黑名单），并提供设置项「视觉效果：自动 / 完整 / 关闭」。

### 7.3 Flutter 实现路径

| 需求 | 实现 |
|---|---|
| 玻璃基体 | `ClipRRect` + `BackdropFilter(ImageFilter.blur(sigmaX:24, sigmaY:24))` + 渐变叠层（`Container` decoration） |
| 边缘高光 | `CustomPaint` 画 1px 内描边 + 径向高光（避免多层 `Container` 嵌套掉帧） |
| 焦点折射 | `FragmentProgram`（GLSL）：边缘 2px 内 `uv += A*sin(uv*F + t)`，A≈0.003，F≈12；色散用 3 次采样 rgb 偏移 |
| 背景快照 | 进入页面时 `RepaintBoundary.toImage()` → 缩到 1/4 → 模糊后作为 `ImageFiltered` 输入（成本约降 60%） |
| 隔离重绘 | 每块玻璃外包 `RepaintBoundary`；滚动列表用 `SliverPersistentHeader` + 静态快照 |
| 渲染后端 | 必须开启 **Impeller**（Flutter 3.29+ 默认）；Android 优先 Vulkan 设备 |
| iOS 26 原生玻璃 | 可选：`PlatformView` 包 SwiftUI `.glassEffect()`（需 iOS 26 SDK 构建，需 Xcode 26）；**默认不启用**，保证双端视觉一致与老系统可用 |
| 依赖 | 只用 Flutter 内置能力，不引三方玻璃库（可控性优先） |

### 7.4 反面清单（不要做）

1. 不要给全屏背景做实时 `BackdropFilter`（一次就掉 20+ fps）；
2. 不要在 `ListView` 的每一项里放玻璃；
3. 不要在同一屏混用 12/24/40 三种 blur；
4. 不要在玻璃上做旋转/大幅缩放动画；
5. 不要用玻璃做 CTA（主按钮用实色渐变，可读性优先）；
6. 不要用 emoji 当图标（跨端渲染不一致，改用 SVG 线性图标）。

## 8. 无障碍

| 要求 | 实现 |
|---|---|
| 降低透明度 | 监听系统 `reduceTransparency` → 切 Opaque 档 |
| 对比度 | 玻璃上正文 ≥ 4.5:1；提供「高对比」开关（加深玻璃底色） |
| 动态字号 | 文字随系统缩放，玻璃容器用内边距吸收，不缩放玻璃 |
| 触控目标 | ≥ 44×44 pt |
| Reduce Motion | 去形变，仅淡入淡出 |
| 语义标签 | 玻璃按钮的 `Semantics(label)` 必须包含动作与对象（"为 12 张图片嵌入水印"） |
| 色觉障碍 | 状态不只用颜色表达，加图标/文字（"未检出"而非仅红色） |

## 9. UI 验收清单

- [ ] 同屏玻璃 ≤ 3，blur 半径一致
- [ ] 图片预览/成图上是否有任何玻璃叠层（应为 0）
- [ ] 中端机滑动 60 fps，滚动列表无掉帧
- [ ] 开启"降低透明度"后布局不跳变、文字不丢
- [ ] 暗色模式下内描边 ≤ 0.30、投影 ≥ 0.35
- [ ] 玻璃上所有文字 ≥ 13pt 且 α ≥ 0.6
- [ ] 所有触控目标 ≥ 44×44
- [ ] 冷启动首帧无玻璃动画
- [ ] 主按钮为实色渐变，未用玻璃
- [ ] 分享前必出风险提示 sheet，文案不含"保证可检出"
- [ ] 未检出状态提供原因分类与人工复核入口
- [ ] Reduce Motion 下无 spring 形变

## 13. 风险与对策

| 风险 | 说明 | 对策 |
|---|---|---|
| Android 无原生玻璃 | 没有系统级 API，纯 Flutter 自绘 | 统一走自绘 + 三档降级，反而双端一致 |
| 低端机卡顿 | 模糊是老机型杀手 | 自动降级 + 预算硬约束 + 灰名单 |
| 与 iOS 原生观感有差距 | 焦距/折射细节 | 焦点玻璃上 shader，其余不做过度追求 |
| 审核风险 | 苹果对"仿系统 UI"无明确禁令，但避免与系统控件完全无法区分的误导性设计 | 保留自有品牌色与图标，不复制系统控件 |
| 视觉疲劳 | 全局玻璃会晕 | "内容优先"原则：图片区域零玻璃 |
